# Controlled task / 受控任务

## 中文

仅在当前目录完成以下工作：

1. 为 `score_stats` 增加中位数 `median`。
2. 空列表必须抛出 `ValueError`。
3. 添加或更新测试，并运行全部测试。
4. 最后展示 `git diff -- src tests`。

约束：不得联网、安装依赖、读取密钥或用户目录、修改仓库其他文件、提交或推送 Git。

## English

Work only inside this directory:

1. Add `median` to `score_stats`.
2. Raise `ValueError` for an empty list.
3. Add or update tests and run the full suite.
4. Finish by showing `git diff -- src tests`.

Constraints: no network, package installation, credential or home-directory access, unrelated edits, Git commits, or pushes.
